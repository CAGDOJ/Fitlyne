# FITLYNE — Loja Pro

Versão 2026-08-06-loja-pro.

Arquivos ativos somente. A configuração do site fica em `fitlyne-config.js` e o backend completo em `Code.gs`.

Principais recursos: Fitness/Makeup/Skincare, SKU automático, prevenção de duplicidade, variações agrupadas no catálogo por modelo/cor, estoque completo, edição/cancelamento de vendas com estorno, catálogo ordenável, frete/prazo, métricas de cliques/pedidos, solicitações de reposição e página de links.

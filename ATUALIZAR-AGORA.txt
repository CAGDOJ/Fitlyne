FITLYNE — ATUALIZAÇÃO LOJA PRO

1) GOOGLE APPS SCRIPT
- Abra o projeto ligado à planilha Fitlyne.
- Substitua TODO o conteúdo do Code.gs pelo Code.gs deste pacote.
- Salve.
- Execute a função setupSystem UMA VEZ e autorize.
- Em Implantar > Gerenciar implantações > editar implantação atual > Nova versão > Implantar.
- NÃO crie uma implantação nova se quiser manter a mesma URL.

2) GITHUB
- Envie os arquivos deste pacote diretamente para a raiz do repositório.
- Preserve o arquivo CNAME; ele contém: fitlyne.shop
- Aguarde o GitHub Pages publicar.

3) CONFIGURAÇÃO
- A URL atual do Apps Script está somente em fitlyne-config.js.
- Para trocar a URL no futuro, altere apenas API_URL nesse arquivo.

4) TESTE
- Abra o painel e confira Produtos, Estoque e Vendas.
- Abra catalog.html e teste filtros, ordenação e carrinho.
- Abra links.html para a página de links.

IMPORTANTE
- setupSystem cria/atualiza colunas e a aba METRICAS, normaliza Fitness/Makeup/Skincare e gera SKU para produtos antigos sem código.
